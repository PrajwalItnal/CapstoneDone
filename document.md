# Running the AI Job Description‑Driven Assessment Blueprint Builder

## Prerequisites

1. **Python 3.9+** installed.
2. **Gemini API key** set in your environment (e.g., add `GEMINI_API_KEY=your_key` to a `.env` file in the project root).
3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Start the FastAPI backend (optional but recommended)

If you want the Streamlit UI to communicate with the FastAPI service, run:
```bash
uvicorn api:app --host 127.0.0.1 --port 8000
```
The backend will be available at `http://127.0.0.1:8000`.

## Launch the Streamlit frontend

```bash
streamlit run jd_assessment_builder.py
```
This starts the Streamlit app on port **8501**. Open one of the URLs shown in the console:
- Local: `http://localhost:8501`
- Network: `http://<your‑ip>:8501`

The UI will automatically detect the backend if it is running; otherwise it falls back to the local Core engine.

## Quick test of the Gemini connection

Within the Streamlit sidebar there is a **"🔑 Test Gemini Connection"** button. Click it to verify that your API key and selected model (default `gemini-3.8-flash`) are working.
